# Xen Installer

![Xen Installer walkthrough, from Welcome to Finished](docs/media/xen-installer-demo.gif)

**Xen Installer** is the new **XeroLinux** graphical installer, built with Python/PySide6 on Qt6/QML. It walks you through language, locale, keyboard, optional software, users and disk partitioning (erase, install alongside another OS, or manual), then installs the system while showing live progress. Branding, colors, and copy come entirely from a per-distro YAML config, no code changes required. Used by XeroLinux, and adaptable to other Arch-based distros.
